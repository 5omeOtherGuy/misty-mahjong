# Third-party assets and libraries

Everything not listed here (game code, the tile faces, the five tile materials and their backs, logo, icon, backgrounds, music, the composition of the sound effects, texts) is original work made for this repository. The tile faces follow the traditional Mahjong set (dots, bamboo, characters, winds, dragons, flowers, seasons), which is centuries old and belongs to nobody; the materials are procedural canvas rendering without image files.

No JavaScript libraries are used: the game is plain ES modules on Canvas 2D and Web Audio. The tools use numpy, scipy, Pillow and ffmpeg at generation time only; nothing of them ships in the app. The VCSL samples ship only as part of the rendered effects.
